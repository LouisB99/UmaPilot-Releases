UmaPilot now uses simple version numbers, starting at **0.1.0**.

- Fixes will increment the last number (0.1.1); new features will increment the middle number (0.2.0).
- This is the next release after v2026.9.9.4. The updater automatically migrates existing installations without reinstalling.
- All existing connection fixes and dashboard update progress remain included. Saved accounts, projects and settings stay in place.

Validated with 45 updater tests, including downloading and installing the transition from date-based versions to 0.1.0.

Choose Check for updates, then quit UmaPilot from its tray menu and reopen UmaPilot.exe when the download is ready. The dashboard will show v0.1.0 after installation.
