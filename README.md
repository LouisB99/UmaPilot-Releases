# UmaPilot releases

Public signed application updates for the Windows portable edition. No accounts, credentials, settings, rosters, or saved results are published here.

Download the one-time updater add-on from [Releases](https://github.com/LouisB99/UmaPilot-Releases/releases/latest). It upgrades the original September 9 portable package without transferring the full installation again. Future published updates download automatically and install after you quit and reopen UmaPilot.

Release manifests and application files are signed before upload. The publishing workflow only verifies checksums and uploads those prepared artifacts; it holds no private signing key.

Only maintainers should change channel/publish.json. Keep historical releases available so installations can catch up safely. Never upload a personal portable ZIP.
